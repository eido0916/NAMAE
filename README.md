# NAMAE

名前・苗字のランキングから海外名を探すNext.js / TypeScript / Tailwind CSSアプリです。入力情報はブラウザーのメモリ内のみで処理します。

## 起動

```sh
npm ci
npm run dev
```

http://localhost:3000 を開きます。PowerShellで実行ポリシーによりnpmが起動できない場合は `npm.cmd` を使用してください。`npm run build` で静的な `out/` を生成し、`npm start` でその成果物を配信できます。

## 今回の修正

- トップの「はると→Noah」診断例と入力フォーム下の固定年度サンプル文を削除。
- 既定の照合を `exactRank` に変更。日本1位なら海外も1位を優先。
- 同じ順位が存在しない国は近い順位の「参考候補」と明示。存在しない順位を作りません。
- 入力年に順位がなければ、その読みが実際にランキング入りした最も近い年を検索し、参考年と実順位を表示。
- 日本の名前辞書と年度別ランキング、米国の年度別ランキング、苗字データを拡充。
- 1920〜2025年の漢字表記ランキング6,863件を追加し、順位根拠を画面に表示。
- 下の名前モードで「はやし」などの苗字に一致した場合は、自動で苗字診断へ切り替えて案内。
- 辞書収録済みで公開順位だけがない名前と、完全な未収録入力を区別。
- 漢字名に複数の読みがある場合は読みを確認。辞書の候補にない読みもかな入力できます。
- 順位不明時のRarity Scoreは画面・保存画像とも算出不可と表示。

## 収録範囲と出典

| データ | 件数・年度 | 用途 |
|---|---|---|
| 日本の名前辞書 | 男女合計8,872読み、漢字・ローマ字の別表記付き | 入力の読み・表記の照合。順位データではありません |
| 日本の漢字表記ランキング | 1920〜2025年、延べ6,863レコード（1,123表記） | 年度・性別ごとの公開調査順位 |
| 日本の読み方ランキング | 2004〜2025年、延べ2,290レコード | 年度・性別ごとの公開調査順位 |
| 日本の苗字 | 1,999姓、調査年度不明 | 辞書内の推定人数を降順で順位付け |
| 米国の下の名前 | 1989〜2020年、各年男女上位200件、延べ12,800レコード | SSA人数順。人数同数は元ファイル順（アルファベット順） |
| 英・仏・韓・独、米国の苗字 | 従来の少数サンプル | 未整備の国。結果にサンプルと表示 |

日本の公開調査は[明治安田の生まれ年別の名前調査](https://www.meijiyasuda.co.jp/enjoy/ranking/index.html)の漢字表記・読み方ランキングです。保険加入者が対象で、全国民の人口順位ではありません。JSONの元順位・同順位を維持しています。漢字入力では漢字表記順位を優先し、該当表記がない場合に読み方順位へフォールバックします。

米国は[SSA](https://www.ssa.gov/oact/babynames/limits.html)の公開データを[hackerb9のミラー](https://github.com/hackerb9/ssa-baby-names)から取得しました。現在は2020年までの収録です。

辞書・苗字は[Japanese Personal Name Dataset](https://github.com/shuheilocale/japanese-personal-name-dataset)（MIT）です。原典とライセンスを `data-sources/japanese-names/` に保存しています。辞書の収録順や別表記の数を人気順位として使用しません。苗字の人数は推定値であり、全国公式統計として扱いません。

## アルゴリズム

`src/lib/engine.ts` にUIから分離しています。`exactRank`（既定）は順位差が最小の名前を選び、同順位未収録なら参考候補と表示します。`normalizedRank`（順位/収録件数）も明示指定で利用可能です。`populationShare` は全比較候補の `share` が必要で、未整備時はエラーになります。

Rarity Scoreは順位/同じ年度・性別の収録件数×100を四捨五入します。人口割合ではありません。未収録名は順位を断定せず、海外の下位20%から入力条件のハッシュによる一定の参考候補を選びます。内部互換のscore=97は順位不明時には表示しません。

読み辞書はランキングを補完するものではありません。かな・ローマ字を照合し、漢字の読みが一意でない場合は利用者に確認します。漢字入力は1920〜2025年の漢字表記順位を優先し、該当表記がなければ2004〜2025年の読み方順位を検索します。入力年に順位がない場合は最も近い掲載年を使い、それでも順位がなければ「名前辞書に収録・公開順位なし」と表示します。

## データ更新

`src/data/<国>/<種別>/*.json` にデータセットを配置し、`src/data/countries.json` に国設定を追加します。1国・1種別につき1データセットで、records内に複数年度を格納できます。

```sh
node scripts/import-name-data.mjs
npm run data:build
```

インポーターはダウンロード済みの `data-sources/rankings/` をキャッシュとして使います。取得範囲はスクリプトに明記されています。ビルドはネットワーク取得せず、同梱データからregistryを再生成します。従来の `generate-sample-data.mjs` は全データを初期サンプルに戻すため、通常運用では実行しないでください。

## 公開・画像・プライバシー

`NEXT_PUBLIC_SITE_URL` に本番URLを設定してビルドしてください。Vercelまたは静的ホスティングで配信できます。DB・外部AI API・解析サービスは不要です。

結果は1080×1920 PNGで保存できます。共有はWeb Share APIを使い、非対応時はコピーまたは画像保存にフォールバックします。国旗はTwemoji（CC BY 4.0）。`public/flags/` にライセンスと出典を保存しています。

入力情報をURL・Cookie・localStorage・サーバーに保存しません。再読み込みすると結果は消えます。利用者が共有操作をした場合のみ共有先に結果を渡します。

`node scripts/export-source.mjs` で全ソースを `SOURCE.md` に出力できます。
