# 名前・名字の追加収録

`node scripts/refresh-mass-name-expansion.mjs` で、WGND 2.0 の国コード付き原本を全対応国へ取り込み、20か国の国籍・出生地・居住地の明示記録を追加集計する。

言語拡張版は使用しない。WGND の `wgt` は人数や人気順位へ変換しない。辞書だけの項目は順位なし、公開人物の確認人数を集計した項目は資料内参考順位として扱う。公人の記録は一般人口を代表せず、出生地・居住地による関連は現在の国籍や名前の文化的起源を意味しない。

国を16か国ずつ処理し、対象外国の大きな補完ファイルを読み込まず、DB生成・検証も国別に順次読み込む。明らかな一文字略記や、一文字だけを3回以上反復したラベルは診断候補から除外する。

変更前は `reports/mass-name-expansion-before.json`、変更後と国別増分は `reports/mass-name-expansion.json` と同名の Markdown に記録する。原本取得済みの再開時だけ `--sources-ready` を指定できる。出生地・居住地を含まない旧キャッシュは、この追加取り込みでは拒否する。

配信データへの反映には `npm run build` を実行する。

大きな辞書には件数に応じて最大256分割した名前検索索引を生成する。入力した名前の区画から該当データファイルの番号を引き、必要な辞書チャンクだけを取得する。小さな辞書・古いマニフェストにも従来の読み込みで対応する。入力名そのものをAPIや検索URLへ送信しない。索引にもチェックサムを付け、通常の配信検証・監視の対象とする。
