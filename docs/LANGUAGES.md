# 表示言語

最初に選んだ名前の国・地域（`sourceCountry`）に合わせ、入力、結果、国の検索、共有画像、名前の詳細、読み方の案内、エラーを表示する。結果カードの国を開いても表示言語は切り替わらない。

17言語、地域差を含め19種類の表示に対応する。

| 言語 | 表示コード | 主な国・地域 |
| --- | --- | --- |
| 日本語 | ja | 日本 |
| 英語 | en | 米国、英国など。未翻訳言語の代替表示 |
| 韓国語 | ko | 韓国 |
| フランス語 | fr | フランスなど |
| ドイツ語 | de | ドイツ、オーストリア、スイスなど |
| イタリア語 | it | イタリア、サンマリノ |
| スペイン語 | es | スペイン、メキシコ、中南米など |
| ポルトガル語 | pt / pt-BR | ポルトガルなど / ブラジル |
| 中国語 | zh / zh-Hant | 中国 / 台湾、香港、マカオ |
| オランダ語 | nl | オランダ、ベルギー |
| スウェーデン語 | sv | スウェーデン |
| デンマーク語 | da | デンマーク |
| ノルウェー語（ブークモール） | nb | ノルウェー |
| フィンランド語 | fi | フィンランド |
| ポーランド語 | pl | ポーランド |
| ロシア語 | ru | ロシア |
| トルコ語 | tr | トルコ |

国から言語への対応は `src/lib/country-locale.mjs`、画面文言は `src/lib/ui-copy.ts` と `src/lib/ui-locales.json`、詳細画面の文言は `src/lib/detail-copy.ts` で管理する。対応外の言語は英語に切り替える。国の母語すべてを翻訳済みという意味ではない。

人物・作品の説明は、公開データに翻訳がある場合に選択言語で表示し、ない場合は英語などの既存表記を使う。名前そのものや出典の内容を自動で翻訳したり、根拠のない読み方を生成したりしない。

確認用テスト: `tests/language-expansion.test.ts`、`tests/language-expansion.browser.spec.ts`。
